# HireMind AI 2.0 Workspace Guidelines

## Environment & Design Philosophy
This project is configured for **state-of-the-art frontend engineering and premium UI/UX design** powered by Google Stitch MCP and Antigravity.

### Active Skills & Standards
- **Premium Frontend Design** (`.agents/skills/premium-frontend-design/SKILL.md`)
- **Motion, Cursor & Character Interactions** (`.agents/skills/motion-cursor-interactions/SKILL.md`)
- **Accessible Component Architecture** (`.agents/skills/accessible-component-architecture/SKILL.md`)
- **Frontend Performance Optimization** (`.agents/skills/frontend-performance-opt/SKILL.md`)
- **Modern Web Guidance** (`GoogleChrome/modern-web-guidance`)
- **Google Stitch MCP Server** (Design system synchronization, screen generation, theme tokens)

### Design & Engineering Directives
1. **Visual Quality**: Sleek dark mode, fluid glassmorphism, dynamic glowing accents, and high visual polish.
2. **Animation**: Natural physics-based easing, cursor-following spotlights, and reactive avatar/character visuals.
3. **Accessibility & Standards**: WCAG 2.1 AA compliant, native HTML5 APIs (Popover, Dialog, Anchor Positioning, Container Queries).
4. **Performance**: Zero-jank interactions, `scheduler.yield()` for batch tasks, and optimized rendering.
